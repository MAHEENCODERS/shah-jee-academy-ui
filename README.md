# Shah Jee Academy – UI/UX Website Design

## 📚 Project Overview

Shah Jee Academy is a modern e-learning platform concept designed for
Sindh Board students from Class IX to XII.

The platform focuses on providing:

- Chapter-wise Notes
- Recorded Lectures
- MCQs & Quizzes
- Student Dashboard
- Progress Tracking
- AI-Powered Student Assistant
- Course & Pricing Section
- Student Login System

## 🎨 UI/UX Design

This project showcases the UI/UX concept and visual design of the
Shah Jee Academy website.
